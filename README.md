# AI Densitometry Quality Control

Сервис искусственного интеллекта для автоматизированной оценки качества
рентгеновских денситометрических исследований (DXA) и корректности разметки
анатомических структур.

## Назначение

Решение принимает на вход денситометрическое исследование в формате DICOM
и выполняет:

- определение анатомической области (поясничный отдел позвоночника /
  проксимальный отдел бедра);
- классификацию исследования как качественного или содержащего нарушение;
- оценку корректности укладки и позиционирования пациента;
- оценку корректности разметки анатомических структур и областей измерения;
- определение одного или нескольких типов нарушения качества;
- формирование структурированного отчёта в формате `.xlsx`.

Поддерживаемые анатомические области:

- **Поясничный отдел позвоночника** — корректная укладка (визуализация верхних
  краев подвздошных костей и половины тела позвонка Th12), выравнивание оси
  позвоночника (допустимый наклон до 5°), отсутствие посторонних предметов
  и артефактов.
- **Проксимальный отдел бедра** — правильное позиционирование (большой вертел,
  шейка бедра, седалищная кость), отсутствие ротации (оценка малого вертела),
  корректность области интереса (3 см сверху/снизу, 2 см по бокам),
  отсутствие посторонних предметов и артефактов.

## Основные возможности

- Пакетная обработка исследований из указанной папки.
- Автоматическое определение анатомической области с OOD-детекцией
  (отклонение нетипичных исследований).
- Сегментация анатомических структур и артефактов нейросетью.
- Геометрический постпроцессинг: расчёт угла наклона оси позвоночника,
  определение ротации бедра, контроль области интереса.
- Формирование итогового отчёта `report.xlsx` с колонками:
  `path_to_study`, `study_uid`, `image_uid`, `anatomical_region`,
  `quality_class`, `violation_type`, `processing_status`,
  `time_of_processing`.
- Визуализация результатов (маски, ключевые точки, углы) для ручной проверки.

## Сборка и запуск

### 1. Сборка окружения

```bash
chmod +x build.sh
./build.sh
```

Скрипт создаёт виртуальное окружение `.venv`, устанавливает зависимости
из `requirements.txt` и создаёт папку `config` при необходимости.

### 2. Подготовка входных данных

Укажите путь к папке с DICOM-исследованиями в файле `config/input.txt`
(одна строка — абсолютный или относительный путь).

### 3. Пакетная обработка

```bash
./run.sh
```

Результат сохраняется в `report.xlsx` в корне проекта.

### 4. Визуализация

```bash
./run_visualization.sh
```

Откроется окно с изображениями, масками и рассчитанными показателями.
Управление: `A` — предыдущее изображение, `D` — следующее, `Q` — выход.

## Формат входных данных

- DICOM-файлы (`.dcm`, `.dicom` или без расширения) в папке,
  указанной в `config/input.txt`.
- Одно исследование может содержать одно или несколько изображений.
- Метаданные DICOM используются для заполнения `study_uid` и `image_uid`.

## Формат выходных данных

Файл `report.xlsx`, одна строка — одно изображение (одна анатомическая область).

| Колонка | Описание | Формат |
|---|---|---|
| `path_to_study` | Путь к исследованию или файлу | String |
| `study_uid` | Идентификатор исследования из DICOM | String |
| `image_uid` | Идентификатор изображения из DICOM | String |
| `anatomical_region` | Определённая анатомическая область | String |
| `quality_class` | 0 — качественное, 1 — есть нарушение | Integer |
| `violation_type` | Тип или перечень нарушений | String |
| `processing_status` | Success / Failure | String |
| `time_of_processing` | Время обработки в секундах | Float |

## Описание модели и обработки

### Предобработка

- Чтение DICOM через `pydicom`.
- Нормализация интенсивностей в диапазон `[0, 255]`.
- Приведение к 3-канальному RGB.
- Масштабирование до 300×300 для инференса.
- Нормализация ImageNet (`mean=[0.485, 0.456, 0.406]`,
  `std=[0.229, 0.224, 0.225]`).

### Модели

- **Классификатор области** — ResNet-18 с OOD-детекцией
  (Mahalanobis distance, косинусная близость к центроидам, softmax-порог).
- **Модель позвоночника** — U-Net (EfficientNet-B0) с 4 классами сегментации
  и двумя вспомогательными классификационными головами (рёбра, артефакты).
- **Модель бедра** — U-Net (EfficientNet-B0) с 5 классами сегментации
  и вспомогательной головой артефактов.

### Постобработка

- Фильтрация мелких связных компонент по площади.
- Расчёт угла наклона оси позвоночника (сегментация по строкам,
  линейная регрессия по окнам).
- Детекция сколиоза по знакопеременным участкам кривой наклона.
- Определение ротации бедра по выступу малого вертела.
- Контроль области интереса по расстояниям до краёв изображения
  (в сантиметрах через коэффициенты `PXX`, `PXY`).

## Известные ошибки и способы их обработки

| Ситуация | Поведение |
|---|---|
| Папка из `config/input.txt` не найдена | Вывод `[ERROR]` и завершение с кодом 1 |
| DICOM-файл повреждён или не читается | Строка с `processing_status = Failure` в отчёте |
| Область не определена (OOD) | `anatomical_region = "Не определена"`, `quality_class = 0` |
| Отсутствуют веса модели | `torch.load` выбросит исключение, запуск прервётся |
| Нет GPU | Автоматический переход на CPU |

## Руководство пользователя

1. Установите зависимости: `./build.sh`.
2. Поместите DICOM-файлы в папку и укажите путь в `config/input.txt`.
3. Запустите `./run.sh`.
4. Откройте `report.xlsx` для просмотра результатов.
5. Для визуальной проверки запустите `./run_visualization.sh`.

## Руководство по развёртыванию

1. Скопируйте проект на целевой сервер.
2. Убедитесь, что установлен Python 3.10+ и (опционально) CUDA.
3. Выполните `./build.sh`.
4. Проверьте веса моделей в `config/`.
5. Настройте `config/input.txt`.
6. Запустите `./run.sh`.
